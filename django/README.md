# Admin Panel And Basic Reports with DJANGO
🦾This project is built on top of django.
With node.js as the main backend tool, django will take care of the admin panel and basic reports functionality of the main project(Fuel station system).

# Stack for this project; Both front and back
🚍Frontend - HTML, Bootstrap, CSS, Js. 
🔙🔚Backend - Django, Python.

# Plan for database
While SQL is the suitable option for our main project (Fuel station system), the team decided to use its one powerful generation MySQL as its core database accross the whole system.
MySQL being the database will handle all data, both input and output and their management as well. The team will focus on using one MySQL Database so everything accross the system is accurate.

# Relationship between Django and Node.js as in this project
Though data is managed by one Database (MySQL database), django will make node.js'job easier by handling the admin panel and basic reports whiles node.js does in return by handling the main backend logic.
